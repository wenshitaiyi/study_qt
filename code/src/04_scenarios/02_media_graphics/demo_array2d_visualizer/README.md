# Demo - 海量 2D 数组与连续过程噪声数据可视化 (demo_array2d_visualizer)

## 1. 简介与功能概览

本项目展示了一个针对海量 2D 数组点阵数据的高性能交互式可视化系统。它将连续数学过程噪声函数、专业科学色带体系（ScientificColourMaps8）、分级视距（LOD）自绘画布管线以及丰富的交互微动效完整融合为一个高内聚、低耦合的可视化工程范式。

### 核心功能列表
1. **多重连续过程噪声发生器**：内置 Perlin 梯度噪声、分形布朗运动（fBm）、Worley 细胞晶格噪声、多频正余弦波干涉场与高斯热源羽流扩散，支持行列规模与连续空间区间 $[x_{min}, x_{max}] \times [y_{min}, y_{max}]$ 自由设定。
2. **多线程异步并发计算**：使用 `QtConcurrent::run` 与 `QFutureWatcher` 实现后台并行采样计算，支持百万级数据点秒级生成且 UI 全程流畅响应。
3. **专业科学色带库 (`code/public/colourmap`)**：基于 ScientificColourMaps8 提取全部 62 款科学防伪色带，支持离散与连续平滑插值采样、256 阶色阶预查表（LUT）纳秒级映射。
4. **Ctrl + 滚轮顶点锚点缩放**：以当前鼠标光标所在的数据坐标为绝对不动点进行无级平滑缩放，极大提升微观局部分析体验。
5. **鼠标拖拽平移与手势交互**：鼠标左键按下拖拽整幅画布，状态指针动态响应。
6. **数值区间与颜色过滤**：支持自定义阈值区间 $[T_{low}, T_{high}]$，超界格子半透明淡化或置灰，快速凸显异常特征峰值。
7. **单元格边框定制**：支持边框显隐控制、颜色选择器与线宽配置，极小缩放下自适应抗摩尔纹弱化。
8. **鼠标圆域浮起动效（Elevation Pass）**：鼠标在画布滑动时，以光标为中心指定圆域 $R$ 内的格子根据余弦空间衰减权重平滑升起、立体微放并投射柔和阴影。
9. **格子内部自适应反色数值展示**：放大至单元格像素 $\ge 36\text{px}$ 时，居中绘制浮点数值，文本前景色根据格子背景亮度自动选择纯黑或纯白反色。
10. **鹰眼小地图（Minimap 缩略图）**：右下角独立小地图展示全局缩略图与当前相机视口红框，支持点击/拖拽快速定位视野。
11. **架构完全解耦**：展示区域（`VisualizerWidget`）、参数控制（`ControlPanel`）、主界面（`MainWindow`）与色带公用模块（`public_colourmap`）独立解耦，通过信号槽进行通信。

## 2. 核心技术点

- **LOD 多级视距绘制管线**：
  - **远景（格宽 < 3px）**：通过全图 1:1 离屏 `QImage` 纹理贴图渲染，百万方格直接走硬件/内存快照贴图，耗时 < 1ms。
  - **中近景（格宽 $\ge$ 3px）**：启用视口裁剪（Viewport Culling），通过坐标投影仅遍历和绘制屏幕当前可见视口范围内的网格。
  - **特写（格宽 $\ge$ 36px）**：追加绘制文本数值层。
  - **浮起动效层**：单独二次 Pass 绘制光标圆域内 elevated 网格，确保浮起格子立体覆盖在平坦格子之上。
- **公用模块抽象 (`code/public/colourmap`)**：
  - 导出 `public_colourmap` 静态链接库，供全局所有 Demo 复用。
  - 管理器在 `main()` 函数中预置路径统一初始化。

## 3. 适用业务场景

- **地质勘探与地理信息系统（GIS）**：数字高程模型（DEM）、地层构造热力图、遥感波段矩阵分析。
- **气象与海洋科学**：多普勒雷达回波图、海表温度场（SST）扩散与洋流密度图。
- **工业检测与 CAE 有限元仿真**：芯片热成像温度分布、应力应变云图、传感器高密阵列巡检。
- **声学与电磁场分析**：声波干涉场图样、天线阵列辐射方向图。

## 4. 编译与运行

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Target demo_array2d_visualizer
```

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1 demo_array2d_visualizer
```
